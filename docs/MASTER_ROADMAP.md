# B47ANCE’d Waterworks Master Roadmap

Canonical version: 0.35.2 (root `VERSION`).

## Implemented

- Authoritative measured fluid transfers, rollback/quarantine, quality/mixing,
  treatment, temperature/freeze state, and container adapters.
- Persistent bounded node/edge networks, topology rebuild, hydraulics, routing,
  connections, subscriptions, diagnostics, lifecycle attachment, and scheduling.
- First-party portable pumps, purifier/heating, valves, fixture claiming, patch
  repairs, leaks/condition, sampling kits, context actions, and sandbox controls.
- powerWorks-backed pump/treatment transactions and exact drain reservation,
  commit, rollback, replay, and inspection.
- Filter definitions/chains, recoverable provider-owned physical-media capacity
  commits, and a strict foreign-plumbing conformance gate.

- Current and legacy Power API resolution with actual-source integration tests
  covering charged devices, exact energy debit, rollback, heating and replay.

- Craftable sediment batch housing, replaceable sand/cloth cartridges, timed
  intent actions, authoritative capacity and conservative interrupted-operation
  quarantine (0.35.0 source/offline only; native crafting and MP NOT TESTED).

## Still to add

- Additional filter types, automatic inline treatment, and verified media/recipe
  balance after runtime acceptance of the implemented sediment batch housing.
- Save migration policy and authenticated remote administration/repair/reset.
- Named third-party adapters only through native fixtures passing conformance.
- foodWorks appliance/preservation consumers using exact drain transactions.
- Basement drainage only after groundWorks topology proof.

## Validation and release gates

- Native objects, servicing, transfer/treatment/repair recovery, scheduling,
  streaming, stress, save/load, late join, hosted, and dedicated servers.
